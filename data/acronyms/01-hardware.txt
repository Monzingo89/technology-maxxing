cpu|CPU|Central Processing Unit|Executes general-purpose program instructions.|Central = the computer's command center; Processing = doing the work.|Core count and clock speed alone do not determine performance.
cpu|ALU|Arithmetic Logic Unit|Performs arithmetic and logical operations inside a processor.|Add, then ask a Logical question: the ALU does both.|It is part of a processor, not the whole CPU.
cpu|CU|Control Unit|Directs instruction execution and coordinates processor operations.|The Control Unit is the conductor cueing the orchestra.|It directs work; the ALU performs arithmetic and logic.
cpu|ISA|Instruction Set Architecture|Defines the instructions and programmer-visible behavior of a processor family.|Instructions are the language; Architecture is its rulebook.|Here ISA means instruction set, not the legacy Industry Standard Architecture bus.
cpu|RISC|Reduced Instruction Set Computer|Uses an instruction-set design emphasizing relatively simple operations.|Reduced recipes: small steps that combine into larger tasks.|RISC does not mean every instruction takes exactly one cycle.
cpu|CISC|Complex Instruction Set Computer|Uses an instruction-set design with relatively complex operations.|Complex instructions can combine several small jobs.|CISC and RISC labels do not directly rank processor speed.
cpu|SoC|System on a Chip|Integrates processing and other system functions on one chip.|A whole System squeezed onto a Chip.|A phone SoC can contain CPU, GPU, and other engines.
cpu|GPU|Graphics Processing Unit|Processes graphics and highly parallel computational workloads.|Graphics means many pixels; many workers process them together.|A GPU is not automatically faster for sequential CPU tasks.
cpu|iGPU|Integrated Graphics Processing Unit|Provides graphics processing integrated with the processor or SoC.|The little i means graphics live inside.|Integrated graphics often share system memory.
cpu|NPU|Neural Processing Unit|Accelerates selected neural-network operations.|Neural = networks; Processing Unit = their specialist.|Model support and numerical formats vary by NPU.
cpu|APU|Accelerated Processing Unit|AMD branding for processors combining CPU and graphics capabilities.|A processor Plus graphics Under one roof.|APU is vendor terminology, not a universal CPU interface.
cpu|DSP|Digital Signal Processor|Processes sampled signals such as audio and radio data.|Digital Sounds Processed quickly.|A DSP specializes in signal operations rather than every computing task.
cpu|FPU|Floating-Point Unit|Performs floating-point arithmetic.|Floating decimal Points have their own arithmetic Unit.|Floating-point representation can introduce rounding error.
cpu|MMU|Memory Management Unit|Translates virtual memory addresses and enforces memory protections.|Memory Maps are managed by the MMU.|Virtual address space is not the same as installed RAM.
cpu|SMT|Simultaneous Multithreading|Allows a core to execute work from multiple hardware threads.|Several Threads share one physical worker at the Same time.|Logical threads are not additional physical cores.
cpu|TDP|Thermal Design Power|Describes a processor's thermal design target under vendor-defined conditions.|Thermal = heat; Design = cooler planning; Power = watts.|TDP is not a universal measurement of maximum electrical draw.
memory|RAM|Random Access Memory|Holds active program data for rapid read and write access.|Reach Any Memory location without reading every prior one.|Ordinary system DRAM loses contents when power is removed.
memory|ROM|Read-Only Memory|Stores data intended to persist with limited or no normal modification.|Read the permanent recipe; do not rewrite it during ordinary use.|Modern firmware may use rewritable flash rather than immutable ROM.
memory|DRAM|Dynamic Random Access Memory|Stores bits in cells that need periodic refresh.|Dynamic = data needs a refresh drink.|DRAM is volatile and differs from persistent storage.
memory|SRAM|Static Random Access Memory|Stores bits without periodic refresh while powered.|Static stays put while power stays on.|SRAM is still volatile; static does not mean permanent.
memory|SDRAM|Synchronous Dynamic Random Access Memory|Coordinates DRAM transfers with a clock.|Synchronous means memory keeps time with a metronome.|SDRAM is a broad family that includes DDR generations.
memory|DDR|Double Data Rate|Transfers data on both edges of a memory clock.|Double = up edge and down edge.|DDR generations are not physically or electrically interchangeable.
memory|DDR2|Double Data Rate 2|Identifies the second DDR SDRAM generation.|Double-edge memory, generation two.|Legacy DDR2 modules cannot fit a DDR4 slot safely.
memory|DDR3|Double Data Rate 3|Identifies the third DDR SDRAM generation.|Three marks the third DDR family.|A matching capacity does not establish motherboard compatibility.
memory|DDR4|Double Data Rate 4|Identifies the fourth DDR SDRAM generation.|Four follows three, but the slot key also changes.|DDR4 and DDR5 desktop modules have different keying.
memory|DDR5|Double Data Rate 5|Identifies the fifth DDR SDRAM generation.|Five is a generation, not five times the transfer rate.|On-die ECC is not equivalent to end-to-end platform ECC memory.
memory|LPDDR|Low-Power Double Data Rate|Reduces memory power consumption for mobile and compact devices.|Low Power helps a phone Live Longer.|LPDDR generations and packaging differ from desktop DIMMs.
memory|GDDR|Graphics Double Data Rate|Provides memory optimized for graphics workloads.|The G puts Graphics before DDR.|GDDR on a graphics card is not a system DIMM replacement.
memory|VRAM|Video Random Access Memory|Holds graphics resources such as frame buffers and textures.|Video's working RAM stores the scene.|VRAM capacity alone does not establish GPU speed.
memory|DIMM|Dual In-line Memory Module|Packages memory with distinct contacts on each side.|Dual sides have distinct electrical contacts.|Check DDR generation, capacity, and platform support.
memory|SO-DIMM|Small Outline Dual In-line Memory Module|Packages removable memory in a compact form often used in laptops.|Small Outline fits a Small Office laptop.|Some laptops use soldered memory instead of removable modules.
memory|ECC|Error-Correcting Code|Detects and corrects supported classes of memory errors.|Errors Can be Corrected.|Correction capability depends on the code and platform implementation.
memory|EEPROM|Electrically Erasable Programmable Read-Only Memory|Retains information that can be electrically erased and reprogrammed.|Two Es: Electrically Erasable.|Write endurance and update granularity vary.
memory|SPD|Serial Presence Detect|Stores module information used to configure supported memory settings.|The module Serially Presents its Details.|Overclocking profiles are not a guarantee of platform stability.
firmware|BIOS|Basic Input/Output System|Initializes hardware and starts a legacy PC boot process.|Basic startup gets Input and Output working.|Modern PCs typically use UEFI firmware instead.
firmware|UEFI|Unified Extensible Firmware Interface|Defines a modern interface between platform firmware and the operating system.|Unified firmware can be Extended with modern boot features.|UEFI support alone does not mean Secure Boot is enabled.
firmware|POST|Power-On Self-Test|Runs startup hardware checks.|Power On, then Self Test before booting.|Beep and diagnostic codes depend on the manufacturer.
firmware|CMOS|Complementary Metal-Oxide-Semiconductor|Names a semiconductor technology associated with legacy PC settings memory.|Complementary transistor partners; remember the PC settings battery.|The CMOS battery does not power the computer's normal operation.
firmware|RTC|Real-Time Clock|Keeps system time while the main system is off.|Real Time Continues while the laptop sleeps.|Time drift can affect certificate and authentication checks.
firmware|TPM|Trusted Platform Module|Protects keys and supports platform trust measurements.|Trusted vault in the Platform stores key Material.|A TPM does not itself encrypt every file.
firmware|ACPI|Advanced Configuration and Power Interface|Coordinates hardware configuration and power management with the OS.|Advanced Computers Power down Intelligently.|Sleep-state availability depends on hardware and firmware.
firmware|MBR|Master Boot Record|Stores legacy boot code and a partition table at a disk's beginning.|Master record begins the Boot story.|Traditional MBR partitioning has limits unlike GPT.
firmware|GPT|GUID Partition Table|Uses globally unique identifiers in a modern disk partition layout.|GUID labels each Partition in the Table.|Here GPT means disk partitioning, not an AI model family.
firmware|PXE|Preboot Execution Environment|Boots a machine using network-delivered startup resources.|Before boot, eXecute an Environment from the network.|PXE needs appropriate network services and trusted boot images.
storage|HDD|Hard Disk Drive|Stores data on rotating magnetic disks.|Hard platters spin in the Disk Drive.|Mechanical movement makes shock and seek time relevant.
storage|SSD|Solid-State Drive|Stores data using nonvolatile solid-state memory.|Solid silicon Stores Data with no spinning platters.|An SSD may use SATA or NVMe; SSD is not a connector type.
storage|SATA|Serial Advanced Technology Attachment|Connects storage devices through a serial ATA interface.|Serial storage travels one lane at a time.|SATA data and power connectors have different roles.
storage|PATA|Parallel Advanced Technology Attachment|Connects older drives using parallel ATA ribbon cables.|Parallel means many wires across a wide ribbon.|Legacy PATA is distinct from SATA.
storage|IDE|Integrated Drive Electronics|Describes the drive-controller integration historically associated with ATA drives.|The drive's Electronics moved Inside.|IDE is also an integrated development environment in software contexts.
storage|AHCI|Advanced Host Controller Interface|Defines a host programming interface commonly used with SATA controllers.|A Host Controls SATA through an Interface.|Changing storage controller mode can prevent an installed OS from booting.
storage|NVMe|Non-Volatile Memory Express|Provides a storage command interface designed for nonvolatile memory over PCIe.|Nonvolatile storage uses the PCIe Expressway.|M.2 describes a form factor; not every M.2 drive uses NVMe.
storage|M.2|M.2 form factor designation|Defines compact expansion module dimensions and connector arrangements.|M.2 is the module's shape, not a promised speed.|M.2 is a designation, not an acronym; keying and protocol support matter.
storage|SCSI|Small Computer System Interface|Defines a family of commands and interfaces for peripheral devices.|Small Computers Speak to storage through an Interface.|SCSI commands can be transported over different technologies.
storage|SAS|Serial Attached SCSI|Connects enterprise storage using serial SCSI transport.|SCSI Attaches Serially.|SAS controller and backplane compatibility must be checked.
storage|RAID|Redundant Array of Independent Disks|Combines disks for selected performance or availability goals.|An Array of disks shares the workload and sometimes survives failure.|RAID is not a backup; RAID 0 provides no redundancy.
storage|NAS|Network Attached Storage|Shares file storage over a network.|Network users Access Shared files.|NAS commonly provides file access, unlike block-oriented SAN access.
storage|SAN|Storage Area Network|Provides a dedicated storage network, often exposing block devices.|Storage has its own Area of the Network.|A SAN is not simply a shared folder.
storage|iSCSI|Internet Small Computer System Interface|Transports SCSI commands over TCP/IP.|Internet packets carry SCSI storage commands.|Storage traffic still needs authentication, segmentation, and capacity planning.
storage|FC|Fibre Channel|Carries high-performance storage networking traffic.|Fibre Channel is a storage highway.|Fibre Channel can use optical or copper media.
storage|LUN|Logical Unit Number|Identifies a logical storage unit.|A Logical storage Unit has a Number.|A LUN need not correspond to one physical disk.
storage|IOPS|Input/Output Operations Per Second|Measures the rate of storage operations.|Count Input and Output jobs Per Second.|Block size, access pattern, and latency are needed to interpret IOPS.
storage|SMART|Self-Monitoring, Analysis and Reporting Technology|Reports drive health and operating attributes.|The drive Monitors itself and Reports warning signs.|A clean SMART report does not guarantee a drive will not fail.
storage|SD|Secure Digital|Names a family of removable flash memory cards.|Small Digital card for portable storage.|Card family, capacity, and speed classes are separate attributes.
storage|microSD|micro Secure Digital|Packages SD storage in a very small removable card.|micro shrinks the Secure Digital card.|A physical adapter does not add support for every capacity family.
storage|eMMC|embedded MultiMediaCard|Provides managed flash storage integrated into a device.|embedded means storage stays on the board.|eMMC performance and serviceability differ from a removable SSD.
storage|UFS|Universal Flash Storage|Provides a serial managed-flash storage standard used in mobile devices.|Universal Flash has a fast serial storage road.|UFS versions and implementations differ in performance.
storage|ODD|Optical Disc Drive|Reads or writes supported optical discs.|Optical light reads a Disc in the Drive.|CD, DVD, and Blu-ray capabilities vary by drive.
storage|DVD|Digital Versatile Disc|Stores data on an optical disc format.|Versatile means video and other digital data.|DVD and CD formats use different capacities and optical characteristics.
bus|PCI|Peripheral Component Interconnect|Connects peripherals using a legacy shared parallel bus.|Peripheral Components Interconnect on a shared road.|Conventional PCI is distinct from PCI Express.
bus|PCIe|Peripheral Component Interconnect Express|Connects devices using high-speed serial point-to-point links.|Express lanes connect each peripheral.|Slot length, electrical lane count, and generation all matter.
bus|PCIe 3.0|Peripheral Component Interconnect Express 3.0|Identifies a PCIe generation operating at 8 GT/s per lane.|Generation three: eight transfers of a billion per second.|GT/s is not the same as usable GB/s.
bus|PCIe 4.0|Peripheral Component Interconnect Express 4.0|Identifies a PCIe generation operating at 16 GT/s per lane.|Four doubles generation three's signaling rate.|A newer device can negotiate a slower supported link.
bus|PCIe 5.0|Peripheral Component Interconnect Express 5.0|Identifies a PCIe generation operating at 32 GT/s per lane.|Five doubles four's per-lane rate.|Platform wiring can limit a long slot to fewer lanes.
bus|PCIe 6.0|Peripheral Component Interconnect Express 6.0|Identifies a PCIe generation with 64 GT/s signaling and PAM4.|Six steps to sixty-four; four signal levels help.|PAM4, error correction, and FLIT operation change link behavior.
bus|AGP|Accelerated Graphics Port|Connects graphics cards on older PCs through a dedicated legacy port.|Accelerated Graphics got its own Port.|AGP cards cannot be installed in a PCIe slot.
power|PSU|Power Supply Unit|Converts input power into regulated outputs for components.|Power is Supplied by this Unit.|Connector fit alone does not guarantee adequate capacity or wiring.
power|UPS|Uninterruptible Power Supply|Provides temporary power when input power fails.|Uninterrupted Power buys time to Save.|A UPS has finite runtime and is not a permanent generator.
power|ATX|Advanced Technology Extended|Defines a PC platform family including board and power supply conventions.|Advanced Technology eXtends the PC layout.|Check exact board size and power connector requirements.
power|DC|Direct Current|Describes current with a single direction of flow.|Direct means one direction.|Laptop internals use regulated DC supplied by power conversion.
power|AC|Alternating Current|Describes current that reverses direction periodically.|Alternating means back and forth.|An adapter converts mains AC to the DC a device requires.
power|ESD|Electrostatic Discharge|Describes a sudden transfer of built-up static charge.|Electric Static jumps and Damages components.|Use appropriate grounding and handling practices during servicing.
display|LCD|Liquid Crystal Display|Modulates light using a liquid-crystal layer.|Liquid Crystals act as tiny light shutters.|Most LCD panels require a backlight.
display|LED|Light-Emitting Diode|Emits light when electrically driven.|A Diode that Emits Light.|An LED-backlit LCD still uses liquid crystals for its pixels.
display|OLED|Organic Light-Emitting Diode|Uses organic emissive elements to create light at pixels.|Organic pixels make their Own Light.|OLED differs from an LCD with an LED backlight.
display|AMOLED|Active-Matrix Organic Light-Emitting Diode|Controls OLED pixels using an active transistor matrix.|Active Matrix manages each Organic light pixel.|AMOLED is an OLED implementation, not an LCD type.
display|IPS|In-Plane Switching|Names an LCD panel technology using in-plane liquid-crystal switching.|In the Plane, crystals Switch orientation.|IPS is a panel technology; it does not specify resolution.
display|TN|Twisted Nematic|Names an LCD panel technology using twisted liquid crystals.|Twisted crystals turn the light.|Panel technology alone does not determine refresh rate or quality.
display|VA|Vertical Alignment|Names an LCD panel technology using vertically aligned crystals.|Vertical crystals Align before the image changes.|Contrast and viewing-angle behavior vary by implementation.
display|TFT|Thin-Film Transistor|Switches individual display elements in active-matrix panels.|Thin Films of Transistors control tiny pixels.|TFT can describe LCD or OLED control circuitry.
display|HDR|High Dynamic Range|Supports a wider range of luminance and color representation than SDR.|High highlights and Deep shadows need Range.|An HDR label does not guarantee high peak brightness.
display|SDR|Standard Dynamic Range|Describes conventional dynamic-range image formats.|Standard brightness Range is the baseline.|SDR and HDR describe image representation, not screen size.
display|FHD|Full High Definition|Commonly identifies a 1920 by 1080 display resolution.|Full HD: remember 1080 rows.|FHD does not specify refresh rate or panel technology.
display|QHD|Quad High Definition|Commonly identifies a 2560 by 1440 display resolution.|Quad 720p pixel count makes 1440p.|QHD and quarter-HD are different labels.
display|UHD|Ultra High Definition|Names a family of high-resolution formats including 3840 by 2160.|Ultra HD often means 2160 rows in consumer 4K.|Consumer 4K UHD differs from 4096-wide digital cinema 4K.
display|PPI|Pixels Per Inch|Measures display pixel density.|Pixels Packed into one Inch.|PPI is not the same as a printer's dots per inch.
display|DPI|Dots Per Inch|Measures dot density in printing or a related device setting.|Dots printed in an Inch.|OS scaling may use DPI terminology without changing physical pixel density.
display|PWM|Pulse-Width Modulation|Controls average power by varying pulse on-time.|Pulse Width sets how long power stays on.|Display dimming behavior and flicker sensitivity vary.
display|VESA|Video Electronics Standards Association|Develops display-related standards including mounting interfaces.|Video Electronics agree on Standards together.|A VESA mount pattern and a DisplayPort capability are different standards.

mobile|SIM|Subscriber Identity Module|Stores credentials used to identify and authenticate a mobile subscription.|Subscriber Identity travels in a Module.|A SIM is not the phone's IMEI.
