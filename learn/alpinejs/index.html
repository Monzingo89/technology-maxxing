Alpine.js

html directives local state and small interactions

Lightweight browser interaction library

Why learn Alpine.js?

Useful for adding local interactions to existing markup. Complex shared application state may need a more deliberate architecture.

Where it came from

Alpine.js adds declarative behavior directly to HTML through directives for state, events, and rendering. It is designed for compact interactive components.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a component with local state.
  2. Toggle an accessible disclosure panel.
  3. Bind an input and display its value.
  4. Render a list with stable keys.
  5. Test keyboard and focus behavior when content changes.
