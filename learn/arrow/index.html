Apache Arrow

interoperable in-memory columnar data and interchange

Columnar memory format and libraries

Why learn Apache Arrow?

Reduces serialization and copying in suitable integrations. Zero-copy exchange depends on compatible representations and is not guaranteed for every conversion.

Where it came from

Apache Arrow defines a language-independent columnar memory format and related tools. It supports efficient analytical data interchange between compatible systems.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Distinguish in-memory Arrow from on-disk Parquet.
  2. Inspect a table's schema and record batches.
  3. Convert a compatible table between two libraries.
  4. Check whether a conversion copies buffers.
  5. Measure memory use while exchanging a large table.
