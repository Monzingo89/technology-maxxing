C

the language operating systems are made of

1972 · Dennis Ritchie / Bell Labs

Why learn C?

You may never ship C, but it explains everything underneath: pointers, memory, why buffer overflows exist. Linux, Python, and most databases are written in it.

Where it came from

Created to write Unix. Its syntax and memory model became the ancestor of C++, Java, C#, JavaScript, and Go.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write hello world; compile with gcc and explain each step.
  2. Implement strlen with pointers.
  3. Explain stack vs heap with a diagram.
  4. Cause (and fix) a segfault deliberately.
  5. Read a small piece of real Linux source.
