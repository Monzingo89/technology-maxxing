CNN (Convolutional Neural Network)

neural networks that learn local spatial features

Architecture family · Deep learning

Why learn CNN (Convolutional Neural Network)?

CNNs reuse learned filters across local regions, producing feature maps that can capture increasingly complex patterns. This structure is useful for image classification and other vision tasks. The Data category groups this concept with its implementation tools: PyTorch and TensorFlow, often used through Python. None of these specific tools is required by the mathematical architecture.

The problem it solves

Learns features from spatially structured inputs instead of relying entirely on manually designed image descriptors. Local connectivity and shared weights reduce parameters relative to a fully connected layer on the same input. Pooling or strided convolutions can reduce spatial resolution; pooling is not mandatory.

Where it came from

LeNet demonstrated convolutional networks for handwritten character recognition in the 1990s. AlexNet's 2012 ImageNet result helped popularize deeper CNNs. Later architectures explored greater depth, multi-scale processing, and residual connections. CNN describes a family of architectures, not a single product or release.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Apply a 3x3 filter to a small grid by hand and explain weight sharing.
  2. Calculate the output dimensions of a convolution with specified stride and padding.
  3. Build a small image classifier and inspect every layer's output shape.
  4. Compare training and validation curves and diagnose overfitting.
  5. Evaluate a pretrained CNN on held-out images and report per-class errors.

More ways to practice

Level 1

Trace a filter

Compute one output value from a 3x3 filter over a 5x5 grid, then shift the filter one column.

Level 2

Check tensor shapes

For a 32x32 RGB image, calculate the output of 16 filters of size 3x3, stride 1, no padding, and dilation 1. Verify with a framework.

Level 3

Train a baseline

Train a small image classifier with separate training and validation data; log layer shapes and compare against a majority-class baseline.

Level 4

Diagnose generalization

Compare learning curves before and after training-only augmentation; explain whether validation performance improves.

Level 5

Audit an evaluation

Evaluate transfer learning on held-out data, grouping related images before splitting. Report a confusion matrix, failure examples, and inference latency.
