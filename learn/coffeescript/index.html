CoffeeScript

concise language that compiles to javascript

2009-12-24 · First release

Why learn CoffeeScript?

Useful for maintaining .coffee codebases and studying compilation. JavaScript is its output language; Node.js provides command-line tooling and can run compiled output. TypeScript is a related compile-to-JavaScript language to compare, not a dependency.

The problem it solves

Offers compact syntax while retaining interoperability with JavaScript libraries.

Where it came from

First released in December 2009, CoffeeScript reached 1.0 in December 2010. Version 2 arrived in September 2017, producing modern JavaScript and supporting async functions and JSX.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write a function that triples a number; predict its output for zero and negative inputs.
  2. Transform a list of temperatures and test an empty list.
  3. Compile a small module and explain its generated JavaScript.
  4. Debug a callback whose receiver changes unexpectedly.
  5. Migrate a module to JavaScript while preserving its tests.

More ways to practice

Level 1

A small function

Implement triple(n) and test -2, 0, and 7.

Level 2

List transformation

Convert Celsius values to Fahrenheit, preserving order and handling an empty list.

Level 3

Inspect compiled output

Compile a statistics helper and explain its return values and variable scope.

Level 4

Callback behavior

Construct a failing receiver-binding test, fix the callback, and explain the result.

Level 5

Behavior-preserving migration

Port the helper to JavaScript and run the same tests against both versions.
