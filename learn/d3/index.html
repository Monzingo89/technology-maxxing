D3.js

data joins scales layouts and browser graphics

Data visualization library

Why learn D3.js?

Useful for custom visual encodings rather than only prebuilt chart types. Correct scales, labels, and accessible alternatives remain essential.

Where it came from

D3 provides JavaScript tools for working with data and creating visualizations using web standards. Its modules include scales, shapes, selections, and data transformations.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Map a numeric domain to a pixel range.
  2. Bind data to chart elements with stable keys.
  3. Add axes and units to a chart.
  4. Update the visualization after data changes.
  5. Provide an accessible table and test misleading scale choices.
