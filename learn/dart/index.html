Dart

client-optimized language for multi-platform apps

2026 · Daily Agent

Why learn Dart?

Dart helps teams build fast, type-safe apps for mobile, web, desktop, and server with one language, strong tooling, and predictable performance.

Where it came from

2011: Google announced Dart to improve large-scale client app development. 2013: Dart 1.0 shipped with a stable language and VM. 2018: Dart 2.0 strengthened the type system for production use. 2021: Dart 2.12 added sound null safety. 2023: Dart 3.0 added records, pattern matching, and new class modifiers.

  • 2011: Google announced Dart to improve large-scale client app development.
  • 2013: Dart 1.0 shipped with a stable language and VM.
  • 2018: Dart 2.0 strengthened the type system for production use.
  • 2021: Dart 2.12 added sound null safety.
  • 2023: Dart 3.0 added records, pattern matching, and new class modifiers.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write a function that takes String? name and int? age, then returns a readable line using defaults when values are null.
  2. Create a User class with final fields, fromJson, and toJson. Parse a list of users and sort by createdAt.
  3. Build a small pipeline: receive events from a Stream, process heavy work in an isolate, and emit typed results with error handling.
  4. Use a switch expression on a record (x, y) to label origin, axis, or quadrant.
  5. Add one package to pubspec.yaml, pin a compatible version constraint, and explain why exact pinning vs range matters.
