dbt (data build tool)

sql-first transformation workflow for analytics

2026 · Daily Agent

Why learn dbt (data build tool)?

dbt turns raw warehouse tables into trusted analytics models using version-controlled SQL. It adds testing, documentation, lineage, and deployment patterns so data teams can ship reliable transformations faster.

Where it came from

2016: dbt was open-sourced by Fishtown Analytics. 2019: Fishtown Analytics rebranded to dbt Labs. Early 2020s: dbt helped define the analytics engineering role. Later releases added semantic-layer and mesh-oriented governance patterns.

  • 2016: dbt was open-sourced by Fishtown Analytics.
  • 2019: Fishtown Analytics rebranded to dbt Labs.
  • Early 2020s: dbt helped define the analytics engineering role.
  • Later releases added semantic-layer and mesh-oriented governance patterns.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a model that selects from a staging table using ref(), then add not_null and unique tests on its primary key.
  2. Build an incremental model for daily orders and explain when full-refresh is required.
  3. Design a CI job that only runs modified nodes using state/defer, and list failure gates before merge.
  4. Define one business metric, document assumptions, and wire it to two downstream models with tests.
  5. Given a failing relationship test, identify root cause, fix model SQL, and prove pass in dbt build output.
