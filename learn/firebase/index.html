Firebase

google's backend platform for apps

2026 · Daily Agent

Why learn Firebase?

Firebase helps teams ship app backends fast without managing most server infrastructure. It provides auth, databases, hosting, serverless functions, analytics, and security tooling in one platform, which is especially useful for mobile and web apps that need real-time data and rapid iteration.

Where it came from

2011: Firebase started as a real-time database service. 2014: Google acquired Firebase. 2016: Firebase expanded into a full app development platform at Google I/O. 2017: Cloud Firestore launched as a scalable document database. 2021: Modular Web SDK (v9) became the modern import style, improving tree-shaking.

  • 2011: Firebase started as a real-time database service.
  • 2014: Google acquired Firebase.
  • 2016: Firebase expanded into a full app development platform at Google I/O.
  • 2017: Cloud Firestore launched as a scalable document database.
  • 2021: Modular Web SDK (v9) became the modern import style, improving tree-shaking.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Build a basic sign-up and sign-in screen with Firebase Authentication (email/password). Show user state on app launch and add sign-out.
  2. Create a Firestore-backed task list with add, toggle complete, and live updates. Use modular SDK imports only.
  3. Write Firestore Security Rules so users can read/write only their own documents. Test with Emulator Suite and include one passing and one failing test case.
  4. Add a Cloud Function that rejects task titles shorter than 3 characters before write completion. Return a clear error to the client.
  5. Implement offline persistence for Firestore in a mobile app flow, then sync changes when connection returns. Display sync status to users.

Catalog research notes

  • Web SDK v9+ modular imports are the standard for smaller web bundles.
  • Cloud Firestore supports aggregation queries (count, sum, average).
  • Firebase Data Connect introduced managed GraphQL over Cloud SQL (preview).
  • Firebase added tighter integrations with Google Cloud and Vertex AI workflows.
