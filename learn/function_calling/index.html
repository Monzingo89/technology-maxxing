Function Calling

connect model outputs to external tools and systems

LLM tool integration pattern

Why learn Function Calling?

Useful when a model needs to trigger APIs, database queries or application logic instead of only returning prose.

Where it came from

Function calling lets AI applications ask a model to emit structured arguments for developer-defined tools and integrations.
