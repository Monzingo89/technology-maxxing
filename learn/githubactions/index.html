GitHub Actions

ci/cd workflow automation in github repos

2026 · Daily Agent

Why learn GitHub Actions?

GitHub Actions automates build, test, release, and deployment steps directly from repository events, reducing manual DevOps work and improving delivery speed, consistency, and auditability.

Where it came from

2018: GitHub Actions launched in public beta. 2019: GitHub Actions became generally available. Reusable workflows and workflow_call enabled DRY pipeline design. Environments added approval gates and deployment protections for safer releases.

  • 2018: GitHub Actions launched in public beta.
  • 2019: GitHub Actions became generally available.
  • Reusable workflows and workflow_call enabled DRY pipeline design.
  • Environments added approval gates and deployment protections for safer releases.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create .github/workflows/ci.yml to run npm ci and npm test on push and pull_request to main.
  2. Extend CI to test Node 18 and 20 using strategy.matrix, and fail fast on test errors.
  3. Add a deploy job that runs only on main after tests pass, uses environment protection, and authenticates to cloud via OIDC (no static secrets).
  4. Extract shared test logic into a reusable workflow and call it from two repositories.
  5. Harden a workflow with least-privilege permissions, pinned action SHAs, and dependency review checks.
