GitLab CI/CD

integrated pipelines for build, test, and deploy

2026 · Daily Agent

Why learn GitLab CI/CD?

GitLab CI/CD automates software delivery inside the same platform where code is planned, reviewed, and merged. It reduces manual release steps, catches defects earlier, standardizes deployments, and adds traceability for audits and incident response.

Where it came from

GitLab CI started as a separate project before being integrated into core GitLab around the GitLab 8.x era. The `.gitlab-ci.yml` file became the central declarative format for defining jobs, stages, and rules. GitLab Runner evolved from early runner tooling into a multi-executor system (shell, Docker, Kubernetes, and more). Capabilities such as Auto DevOps, review apps, child pipelines, and merge trains broadened CI/CD from simple testing to full delivery orchestration.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write a `.gitlab-ci.yml` with `build` and `test` stages for a Node.js app. Use `node:20`, run `npm ci`, `npm run build`, and `npm test`.
  2. Add caching and artifacts so tests can reuse dependencies and build output. Use `needs` to reduce stage wait time.
  3. Add a `deploy_prod` job that runs only on `main`, requires a manual action, and publishes an environment named `production`.
  4. Refactor one large pipeline into parent-child pipelines. Keep lint/test in parent and trigger service-specific child pipelines.
  5. Add a merge-request pipeline rule that runs SAST and fails the pipeline on high-severity findings.

Catalog research notes

  • Reusable CI/CD components and template composition have expanded for standardizing pipelines across projects.
  • Policy-driven compliance and security checks are more deeply enforced at merge request and pipeline levels.
  • Runner scalability has improved with stronger autoscaling patterns for container and cloud workloads.
  • Pipeline UX improvements continue in areas like downstream pipelines, merge trains, and deployment visibility.
