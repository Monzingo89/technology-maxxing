Go (Golang)

compiled language for concurrent networked software

2026 · Daily Agent

Why learn Go (Golang)?

Go helps teams ship fast, reliable backend and infrastructure software with simple syntax, built-in concurrency (goroutines/channels), strong standard tooling, and easy static-binary deployment.

Where it came from

Designed at Google by Robert Griesemer, Rob Pike, and Ken Thompson (work started in 2007). Publicly announced in 2009 and open-sourced soon after. Go 1.0 released in 2012 with a strong compatibility promise. Go modules became the default dependency system in Go 1.16.

  • Designed at Google by Robert Griesemer, Rob Pike, and Ken Thompson (work started in 2007).
  • Publicly announced in 2009 and open-sourced soon after.
  • Go 1.0 released in 2012 with a strong compatibility promise.
  • Go modules became the default dependency system in Go 1.16.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Build a command-line tool that converts Celsius to Fahrenheit and vice versa. Keep the full solution under 60 lines, validate bad input, and print helpful usage text.
  2. Create an HTTP server with `/health` returning JSON: `{ "status": "ok" }`. Add proper status code, content-type header, and one unit test for the handler.
  3. Implement a 3-stage pipeline (generate -> transform -> aggregate) using goroutines and channels. Add `context.Context` cancellation and ensure no goroutine leaks.
  4. Create a Go module that wraps a public REST API. Include retries with backoff, context-aware timeouts, and table-driven tests for success/error paths.
  5. Take a CPU-heavy function, profile it with `pprof`, optimize one hotspot, then run with PGO and compare benchmark results before/after.

Catalog research notes

  • Go 1.22 changed loop-variable semantics to per-iteration scope, reducing common closure bugs.
  • Go 1.22 added integer range loops (`for i := range 10`) and upgraded `net/http` routing patterns.
  • Go 1.21 introduced toolchain management improvements and the `min`, `max`, and `clear` built-ins.
  • PGO became production-ready in Go 1.21, making practical performance tuning easier.
