Groovy

dynamic and static java-compatible scripting

JVM programming language

Why learn Groovy?

Useful for JVM automation and understanding Gradle or Jenkins scripts. Dynamic conveniences should not obscure validation or runtime dependencies.

Where it came from

Apache Groovy is a JVM language supporting both dynamic and static programming styles. It interoperates with Java and supports concise scripting and domain-specific languages.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Call a Java library from a script.
  2. Transform a collection with a closure.
  3. Handle an optional property safely.
  4. Compare dynamically and statically checked code.
  5. Test a build helper independently of the build server.
