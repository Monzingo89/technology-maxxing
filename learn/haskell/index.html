Haskell

static types lazy evaluation and explicit effects

Pure functional programming language

Why learn Haskell?

Useful for exploring typed functional design and compositional programs. Evaluation behavior and abstraction choices affect memory use and approachability.

Where it came from

Haskell is a statically typed, purely functional language with lazy evaluation. Its type system and abstractions distinguish pure computations from effectful actions.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Define an algebraic data type.
  2. Handle every constructor with pattern matching.
  3. Compose pure list transformations.
  4. Keep input/output separate from pure logic.
  5. Test properties over generated input cases.
