HTML

the document skeleton of the web

1993 · Tim Berners-Lee / W3C·WHATWG

Why learn HTML?

Every page on the web is HTML at the end of the pipeline. Frameworks come and go; HTML is the contract they all compile to. Non-negotiable knowledge.

The problem it solves

HTML provides the universal structure and meaning of web content, making pages readable by browsers, search engines, and assistive technologies while enabling responsive mobile layouts.

Where it came from

Created at CERN as a simple markup for sharing physics documents. Standardized through browser wars, nearly replaced by XHTML, then reborn as the living HTML5 standard.

  • 1991: Tim Berners-Lee published the first HTML tag set for linked documents.
  • 1995: HTML 2.0 became the first formal standard.
  • 1997: HTML 4.x emphasized separation of structure from presentation (with CSS).
  • 2014: HTML5 became a major milestone with semantic elements and rich media support.
  • Now: WHATWG maintains HTML as a Living Standard with ongoing incremental improvements.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Build a page using only semantic tags (no divs).
  2. Make an accessible form with labels & fieldsets.
  3. Explain the difference between <section>, <article>, <aside>.
  4. Hand-write a valid document with meta tags for SEO/social.
  5. Audit a real site's markup with a11y devtools and fix 5 issues.

More ways to practice

Level 1

5-Minute Semantic Upgrade

Replace a `div`-only page with `header`, `main`, `section`, and `footer`. Keep it to one phone screen.

Level 2

Accessible Image Card

Build a card with an image, heading, short text, and link. Use meaningful `alt` text and logical heading order.

Level 3

Mobile Form Essentials

Create a sign-up form using `label` + matching `id`, proper input types (`email`, `tel`), and `required` fields.

Level 4

Daily Reflection Snippet

Write a short journal entry using semantic text tags (`article`, `time`, `p`) and validate the HTML.

Level 5

Mini Landing Page Skeleton

Create a fast-loading page skeleton with viewport meta, semantic landmarks, and lazy-loaded image placeholders.

Catalog research notes

  • HTML is a Living Standard (continuous updates), not a versioned "HTML6" release model.
  • Modern declarative attributes like `popover` and `inert` reduce JavaScript needed for common UI behavior.
  • Performance-oriented attributes such as `loading="lazy"` are widely used for faster mobile pages.
  • Form and accessibility mappings are continually refined for better assistive-tech and cross-browser consistency.
