Jupyter

notebooks kernels reproducible computational documents

Interactive computing ecosystem

Why learn Jupyter?

Useful for exploration and communicating analysis. Hidden execution state can undermine reproducibility unless notebooks are rerun from a clean kernel.

Where it came from

Project Jupyter develops interactive computing tools that combine executable code, outputs, and narrative in notebooks. Kernels connect notebook interfaces to different programming languages.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a notebook with code, a chart, and interpretation.
  2. Inspect which kernel runs the notebook.
  3. Restart the kernel and run every cell in order.
  4. Move reusable logic into an importable module.
  5. Reproduce the notebook with a documented environment.
