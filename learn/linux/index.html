Linux

the OS running (almost) all servers

1991 · Linus Torvalds

Why learn Linux?

Every deployment path ends at a Linux box or container. Shell fluency is the difference between using the cloud and understanding it.

Where it came from

A hobby kernel, joined with GNU tools, that beat commercial Unix. Today it runs the cloud, Android, supercomputers, and your router.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Navigate & manipulate files purely in the shell.
  2. Explain permissions (chmod 755) precisely.
  3. Pipe 3 commands together to solve a real task.
  4. Write a bash script with args and error handling.
  5. Trace a slow process with top/ps/journalctl.
