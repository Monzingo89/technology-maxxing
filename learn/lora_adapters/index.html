LoRA Adapters

low-rank trainable adapters for efficient model adaptation

Parameter-efficient fine-tuning method

Why learn LoRA Adapters?

Useful when teams need specialized model behavior without the cost of full fine-tuning every model weight.

Where it came from

LoRA freezes base model weights and trains smaller low-rank matrices, reducing the number of trainable parameters for adaptation.
