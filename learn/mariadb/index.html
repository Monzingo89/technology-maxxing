MariaDB

open-source relational database server

2026 · Daily Agent

Why learn MariaDB?

MariaDB provides a reliable SQL database for transactional apps, analytics-friendly querying, and MySQL-oriented migration paths while staying open source and self-hostable.

Where it came from

2009: MariaDB was started by Michael "Monty" Widenius as a MySQL fork. It emerged after concern about MySQL stewardship following Oracle's Sun acquisition. MariaDB kept strong MySQL protocol and SQL compatibility to reduce migration friction. Over time it added MariaDB-specific capabilities and diverged in some features/behavior. The MariaDB Foundation supports community development, with commercial support also available.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a tasks table with id, title, status, created_at. Insert 5 rows, then return only rows where status='open' ordered by created_at DESC.
  2. Given an orders table, add an index on (customer_id, created_at). Run EXPLAIN for a customer history query before and after, and note what changed.
  3. Write a transfer script using START TRANSACTION, two UPDATE statements, and COMMIT/ROLLBACK handling. Include one failing case and verify balances stay consistent.
  4. Design a minimal primary-replica setup plan: binary logging, user privileges, backup seed, replication status checks, and failover caveats.
  5. Plan a zero-downtime column migration: add new column, backfill in batches, dual-write window, cutover query, and rollback steps.
