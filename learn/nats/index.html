NATS

subjects pub-sub request-reply and jetstream

Messaging system

Why learn NATS?

Useful for connecting services through lightweight message exchange. Delivery guarantees depend on the selected messaging mode and acknowledgment design.

Where it came from

NATS provides messaging primitives such as publish/subscribe and request/reply. JetStream adds persistence and streaming facilities distinct from core transient messaging.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Publish and subscribe on a test subject.
  2. Implement a bounded request-reply exchange.
  3. Contrast Core NATS with a JetStream stream.
  4. Test consumer acknowledgment and redelivery.
  5. Make a message handler idempotent under repeated delivery.
