Netlify

git-based cloud platform for modern web apps

2026 · Daily Agent

Why learn Netlify?

Netlify makes web app delivery simpler by combining Git-based deploys, global CDN hosting, serverless/edge compute, and team workflows (like preview URLs) in one platform.

Where it came from

Netlify was founded in 2014 by Mathias Biilmann and Christian Bach. It became a key platform in the rise of the JAMstack approach. Deploy Previews helped popularize branch/PR-based review workflows for frontend teams. Netlify expanded from static hosting into serverless functions, edge functions, and broader composable web tooling.

  • Netlify was founded in 2014 by Mathias Biilmann and Christian Bach.
  • It became a key platform in the rise of the JAMstack approach.
  • Deploy Previews helped popularize branch/PR-based review workflows for frontend teams.
  • Netlify expanded from static hosting into serverless functions, edge functions, and broader composable web tooling.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Connect a GitHub repo to Netlify, trigger a deploy from main, and share the production URL.
  2. Open a PR with a UI text change, verify the Deploy Preview URL, and post the preview link in your PR comment.
  3. Create a function that returns JSON at /.netlify/functions/hello and call it from your frontend.
  4. Use netlify.toml to add an SPA fallback redirect and a cache header rule for /assets/*.
  5. Implement an edge function that reads a query param and injects a greeting response header.
