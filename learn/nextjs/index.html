Next.js

react framework for full-stack web apps

2026 · Daily Agent

Why learn Next.js?

Next.js removes repetitive React infrastructure work by combining routing, rendering modes (SSR/SSG/ISR), backend endpoints, and performance defaults (images, fonts, code splitting) into one production-ready framework.

Where it came from

2016: Released by ZEIT (now Vercel) to simplify server-rendered React apps. 2019–2020: Static generation and Incremental Static Regeneration (ISR) became core capabilities. 2021: Next.js 12 introduced the SWC compiler and Edge Middleware. 2022: Next.js 13 introduced the App Router and React Server Components model. 2023+: App Router matured with stronger streaming, caching, and server-action workflows.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Given an app/profile/page.tsx screen with a button and local state, decide which file needs 'use client' and explain why in 2-3 lines.
  2. Create app/posts/[slug]/page.tsx that fetches a post by slug. If fetch fails, render notFound(). Keep UI to title + short body preview.
  3. Design a page that serves cached content but refreshes every 60 seconds. Briefly justify when ISR is better than full SSR for this case.
  4. Build app/api/notes/route.ts with GET and POST. Return JSON, validate required fields, and use proper HTTP status codes.
  5. You observe slow first load and large JS bundle. List 3 Next.js-specific fixes and map each fix to a measurable metric (LCP, TTFB, JS KB).

Catalog research notes

  • App Router is now the primary direction for new projects, with nested layouts and streaming-first UX.
  • Turbopack development workflows continue to improve local build and refresh speed.
  • Server Components patterns are more mainstream: server by default, client only when needed.
  • Recent releases refined caching controls and async request handling in route logic.
  • Ongoing alignment with newer React releases and modern TypeScript tooling remains a core focus.
