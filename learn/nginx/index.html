NGINX (nginx)

event-driven reverse proxy and web server

2026 · Daily Agent

Why learn NGINX (nginx)?

NGINX serves static files quickly and handles high concurrency with low memory use. It is widely used as a reverse proxy to route requests to app servers, terminate TLS, load balance traffic, cache responses, and enforce limits.

Where it came from

Created by Igor Sysoev to solve C10k-style concurrency limits. First public release was in 2004. NGINX, Inc. was founded in 2011 to support commercial adoption. F5 acquired NGINX in 2019.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write a server block that listens on port 80 and serves /var/www/site with index.html as the default file. Validate with nginx -t, then reload safely.
  2. Route /api/ traffic to a local Node service on port 3000. Preserve Host and client IP headers. Confirm behavior with curl and access logs.
  3. Create an upstream with two app servers, proxy / to it, enable rate limiting for bursts, and add security headers for common browser protections.
  4. Model blue/green upstream pools and switch traffic with minimal downtime using a single config change plus reload.
  5. Configure short-lived proxy cache for GET responses and bypass cache on Authorization headers. Measure hit ratio from logs.
