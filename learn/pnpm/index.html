pnpm

shared package storage lockfiles and workspaces

JavaScript package manager

Why learn pnpm?

Useful for dependency management across projects and monorepos. Lockfile discipline and explicit dependency declarations improve reproducibility.

Where it came from

pnpm manages JavaScript dependencies using a shared content-addressable store and linked project installations. It also supports multi-package workspaces.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Install dependencies and inspect the lockfile.
  2. Run a project script through pnpm.
  3. Declare dependencies in the package that uses them.
  4. Create a two-package workspace.
  5. Verify a frozen-lockfile install in a clean environment.
