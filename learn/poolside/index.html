Poolside

ai coding models and controlled agent workflows

2026-05-05 · Poolside Platform announcement

Why learn Poolside?

Placed in DevOps & Tooling because it assists software delivery: code changes, tests, refactoring, and automated engineering tasks. Python and TypeScript connect through documented API examples; HTTP connects through its model API; AWS connects through the documented EKS deployment option. These are usage and deployment relationships, not implementation-language claims.

The problem it solves

Helps teams apply coding agents to engineering work while choosing where model inference runs and how tool execution is controlled. Hosting and governance requirements should be evaluated for the selected access method.

Where it came from

Poolside develops software-engineering foundation models and agent tooling. Its May 5, 2026 Platform announcement emphasized enterprise-controlled execution and governance. Current documentation also describes hosted inference and publicly released Laguna model weights. The announcement date refers to the Platform, not the company's founding.

  • The Poolside Platform announcement is dated May 5, 2026.
  • Current documentation identifies Laguna as Poolside's agentic coding model family.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Explain how Poolside's model, agent CLI, and Platform differ, citing the official overview.
  2. Sketch an HTTP model request using the documented endpoint and a placeholder credential; do not send it.
  3. Plan a small refactoring task with a baseline test, acceptance criteria, and a review of the resulting diff.
  4. Compare hosted inference with self-managed inference for a hypothetical private repository.
  5. Design an evaluation of agent-generated patches using held-out tasks, test results, review time, and rollback criteria.

More ways to practice

Level 1

Identify the components

Explain the distinction between model inference and an agent that invokes tools.

Level 2

Trace a request

Annotate an example HTTP request with its base URL, endpoint, authentication header, model, and messages. Use placeholders only.

Level 3

Specify a refactoring task

Write acceptance criteria and a regression test plan for an agent-assisted refactor of a toy project.

Level 4

Choose an access method

Draw the data boundary for hosted versus self-managed inference and identify the operational responsibilities of each.

Level 5

Evaluate patch quality

Define a reproducible patch evaluation with held-out tasks, baseline results, human review, and failure reporting.
