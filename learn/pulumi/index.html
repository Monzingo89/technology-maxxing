Pulumi

infrastructure as code with real programming languages

2026 · Daily Agent

Why learn Pulumi?

Pulumi lets teams define, deploy, and manage cloud infrastructure using familiar programming languages (TypeScript, Python, Go, C#, Java), reducing context switching and enabling reusable, testable infrastructure code.

Where it came from

2017: Pulumi was founded to modernize infrastructure as code with general-purpose languages. 2018: Early public releases introduced multi-cloud IaC with a developer-first workflow. 2019: Pulumi 1.0 launched. 2020+: Automation API enabled embedding Pulumi operations inside custom apps and platforms. 2023+: Pulumi ESC (Environments, Secrets, and Configuration) expanded secret/config management across projects.

  • 2017: Pulumi was founded to modernize infrastructure as code with general-purpose languages.
  • 2018: Early public releases introduced multi-cloud IaC with a developer-first workflow.
  • 2019: Pulumi 1.0 launched.
  • 2020+: Automation API enabled embedding Pulumi operations inside custom apps and platforms.
  • 2023+: Pulumi ESC (Environments, Secrets, and Configuration) expanded secret/config management across projects.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a new Pulumi project in TypeScript, provision one S3 bucket, run pulumi preview, then pulumi up. Capture the output value and destroy the stack.
  2. Use pulumi config to store a plain region and one secret API key. Read both in code, deploy a resource, and confirm the secret is encrypted in state.
  3. Build a reusable ComponentResource that creates a bucket + IAM policy attachment. Instantiate it twice with different names and tags, then export both outputs.
  4. Which command previews changes without applying them?
  5. Pulumi can store state in Pulumi Cloud or self-managed backends like S3/Azure Blob/GCS.
