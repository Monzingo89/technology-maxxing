Python

readable general-purpose language; king of data & AI

1991 · Guido van Rossum

Why learn Python?

The default language of AI, automation, and data pipelines. If a task touches ML or glue-code, Python is probably the shortest path.

Where it came from

Designed for readability ('executable pseudocode'). Grew from scripting into web (Django/Flask), then conquered data science and machine learning.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Solve 5 problems with list comprehensions.
  2. Parse a CSV and summarize it (no pandas, then pandas).
  3. Write a decorator and explain closures.
  4. Call a REST API and cache responses.
  5. Explain the GIL and when it matters.
