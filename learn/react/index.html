React

component UI library, one-way data flow

2013 · Meta

Why learn React?

Largest frontend ecosystem and job market. Even if you use something else, its component model is the industry's shared mental model.

Where it came from

Born from Facebook's news-feed complexity. The virtual DOM and 'UI as a function of state' idea reshaped frontend thinking; hooks (2019) reshaped it again.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Build a counter with useState; explain re-renders.
  2. Lift state up between two components.
  3. Fetch & display data with useEffect correctly (deps array!).
  4. Build a custom hook (useLocalStorage).
  5. Explain reconciliation and when to use memo/useMemo.
