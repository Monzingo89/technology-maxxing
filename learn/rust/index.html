Rust

a memory-safe systems programming language

2026 · Daily Agent

Why learn Rust?

Rust helps you build fast, low-level software with strong memory safety guarantees and no garbage collector. It reduces common bugs (null misuse, use-after-free, data races) while keeping C/C++-class performance.

Where it came from

Started by Graydon Hoare in 2006; first announced publicly by Mozilla in 2010. Rust 1.0 (stable) released in 2015. Cargo became a major productivity advantage for builds and dependency management. Rust Foundation launched in 2021 to support governance, trademarks, and ecosystem stewardship. Rust editions (2015, 2018, 2021, 2024) allow language evolution with smoother migration.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write a function that takes a String, returns its length, and explain why the original variable is moved.
  2. Implement a function that returns the first word of a &str as a slice (&str) without allocating.
  3. Build a thread-safe counter with Arc<Mutex<i32>> across 4 threads and print the final value.
  4. Read a text file into String using Result and ?; propagate errors instead of panicking.
  5. Create a tiny CLI that accepts a filename and word, then counts matching lines safely.
