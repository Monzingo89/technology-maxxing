SQL

the universal language of data

1974 · Chamberlin & Boyce / IBM

Why learn SQL?

Fifty years old and more relevant than ever — Postgres, Snowflake, and even Kafka speak dialects of it. The single highest-ROI skill in data.

Where it came from

Based on relational theory (Codd, 1970). Survived object databases, survived NoSQL hype, and remains the query language even 'NoSQL' systems eventually add.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write SELECT/WHERE/ORDER on a sample table.
  2. JOIN two tables; explain inner vs left.
  3. GROUP BY with HAVING to find duplicates.
  4. Write a window function (running total).
  5. Read an EXPLAIN plan and add the right index.
