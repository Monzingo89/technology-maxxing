SQLite

an embedded serverless relational database engine

2026 · Daily Agent

Why learn SQLite?

SQLite gives apps a zero-admin SQL database in a single file, ideal for local storage, offline-first features, testing, edge deployments, and small-to-medium production workloads without running a separate database server.

Where it came from

2000: Created by D. Richard Hipp to avoid external DB dependencies. 2004: SQLite 3.0 shipped with a new architecture and lasting file-format stability. 2010s: Became default storage in many mobile, desktop, browser, and IoT stacks. 2021: STRICT tables (3.37) added stronger type enforcement options. 2024: JSONB support (3.45) improved JSON storage/performance patterns.

  • 2000: Created by D. Richard Hipp to avoid external DB dependencies.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a notes table (id, title, body, created_at). Write SQL to insert 3 notes, list newest first, and update one title.
  2. Given a tasks table with 10k rows, design one index for: WHERE status = 'open' AND due_date < ? ORDER BY due_date. Verify using EXPLAIN QUERY PLAN.
  3. Model a sync_queue table for pending API writes. Add retry_count and last_error fields, then write queries to fetch next 20 unsynced rows and mark one as synced atomically.
  4. Migrate a loose-typed expenses table into a STRICT table, preserving data quality and rejecting invalid rows. Document each migration step.
  5. Enable WAL mode, run concurrent read/write simulation, and compare behavior with DELETE journal mode in a short summary.
