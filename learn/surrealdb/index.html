SurrealDB

records graph relationships and surrealql

Multi-model database

Why learn SurrealDB?

Useful for exploring connected application data in one system. Permissions, schema choices, and supported deployment modes require explicit validation.

Where it came from

SurrealDB combines multiple data-model features, including records and graph relationships, behind its query language and database interfaces.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Define a small table and sample records.
  2. Link records with a relationship.
  3. Query records and their connections.
  4. Configure and test record access rules.
  5. Test invalid input under the selected schema mode.
