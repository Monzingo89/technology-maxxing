Test-Driven Development (TDD)

test-first workflow for safe code evolution

2026 · Daily Agent

Why learn Test-Driven Development (TDD)?

TDD lowers regression risk and improves code design by turning requirements into executable tests before implementation, creating fast feedback and safer refactoring.

Where it came from

TDD grew from 1990s xUnit testing patterns in the Smalltalk community. Kent Beck formalized TDD within Extreme Programming (XP). The Red-Green-Refactor loop became the standard micro-cycle. TDD spread broadly through tools like JUnit, NUnit, RSpec, and pytest.

  • TDD grew from 1990s xUnit testing patterns in the Smalltalk community.
  • Kent Beck formalized TDD within Extreme Programming (XP).
  • The Red-Green-Refactor loop became the standard micro-cycle.
  • TDD spread broadly through tools like JUnit, NUnit, RSpec, and pytest.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Write one failing unit test for a function `is_even(n)` before writing any implementation. Keep the test name behavior-focused.
  2. Implement `is_even(n)` using the smallest change needed to pass your failing test, then add two more tests for edge cases (0 and negative values).
  3. Given a working `calculate_total(items, tax_rate)` function and passing tests, refactor for readability (extract helper methods) without changing behavior.
  4. A production bug shows discounts above 100% are accepted. First add a failing test that reproduces the bug, then patch the code and keep all prior tests green.
  5. Run mutation testing on a small module and add tests that kill at least three surviving mutants. Explain what behavior each new test protects.

Catalog research notes

  • TDD is increasingly enforced by CI merge gates that require passing tests.
  • Teams often pair TDD with mutation testing to check test quality, not just coverage.
  • Property-based testing is more commonly used with TDD to uncover edge cases early.
  • AI-assisted test drafting is rising, but human review remains essential for intent and clarity.
