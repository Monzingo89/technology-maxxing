TypeScript

JavaScript with static types

2012 · Anders Hejlsberg / Microsoft

Why learn TypeScript?

De-facto standard for serious JS projects — Angular requires it, React teams default to it. Catches bugs before runtime; large refactors become safe.

Where it came from

Microsoft's answer to large JS codebases becoming unmaintainable. A superset that compiles to JS, it won by meeting developers where they were.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Convert a small JS file to TS with zero any.
  2. Type a fetch wrapper with generics.
  3. Explain interface vs type alias.
  4. Model a discriminated union for API responses.
  5. Write a mapped/conditional utility type and explain it.
