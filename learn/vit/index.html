Vision Transformer (ViT)

image patches processed with transformer attention

2020-10-22 · Original preprint; ICLR 2021

Why learn Vision Transformer (ViT)?

ViT embeds image patches as tokens, adds positional information, and processes them with Transformer blocks. Self-attention relates patches across the image. CNNs provide a useful comparison because their local filters encode different architectural assumptions. Neither approach is universally superior: compare accuracy, pretraining data, compute, and latency on the same task.

The problem it solves

Provides an attention-based way to learn image representations. Standard global self-attention models relationships between all patch tokens; its pairwise attention computation grows quadratically with sequence length. Smaller patches or larger images increase the token count.

Where it came from

Dosovitskiy and colleagues introduced ViT in an October 2020 preprint, subsequently published at ICLR 2021. The work applied a Transformer to sequences of image patches and demonstrated strong image-recognition results after large-scale pretraining. ViT is an architecture family, not a product with one current release.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Split a 224x224 image into non-overlapping 16x16 patches and count the tokens.
  2. Trace shapes from flattened RGB patches through a learned projection.
  3. Run a pretrained ViT using the preprocessing specified for its weights.
  4. Compare a CNN and ViT on the same held-out image split.
  5. Measure the accuracy, memory, and latency impact of changing image resolution.

More ways to practice

Level 1

Count patch tokens

Calculate tokens for 224x224 images using 16x16 patches. Explain whether your count includes a class token.

Level 2

Trace patch embeddings

Calculate flattened RGB patch dimensions and the output shape after projection to an embedding width of 192.

Level 3

Pretrained inference

Load a pretrained ViT, use its documented preprocessing, and record predictions on a small labeled image set.

Level 4

Compare architectures

Compare a CNN and ViT with the same data split; disclose different pretraining datasets and compute budgets.

Level 5

Resolution tradeoffs

Measure accuracy, peak memory, and latency at supported resolutions; document any positional-embedding adaptation.
