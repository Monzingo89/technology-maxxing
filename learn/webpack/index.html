Webpack

a js module bundler and asset build pipeline

2026 · Daily Agent

Why learn Webpack?

Webpack converts many frontend files into optimized deployable bundles. It manages dependency graphs, transformations, code splitting, and cache-friendly output for reliable CI/CD releases.

Where it came from

2012: Tobias Koppers began webpack to bundle browser-focused JavaScript modules. 2017: Webpack 2 strengthened ES module workflows and tree-shaking behavior. 2018: Webpack 4 introduced mode (development/production) and more zero-config defaults. 2020: Webpack 5 added Module Federation, persistent caching, and removed automatic Node core polyfills.

  • 2012: Tobias Koppers began webpack to bundle browser-focused JavaScript modules.
  • 2017: Webpack 2 strengthened ES module workflows and tree-shaking behavior.
  • 2018: Webpack 4 introduced mode (development/production) and more zero-config defaults.
  • 2020: Webpack 5 added Module Federation, persistent caching, and removed automatic Node core polyfills.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Create a minimal webpack.config.js with entry, output to dist, production mode, and clean builds. Run build and verify a hashed bundle file.
  2. Add CSS handling (style-loader + css-loader) and configure splitChunks for shared vendor code. Compare bundle sizes before and after.
  3. Given an older config, remove deprecated patterns, handle Node polyfill changes explicitly, and enable persistent cache for faster rebuilds.
  4. Set deterministic chunk names and contenthash output. Explain how this improves browser cache hit rate during frequent deployments.
  5. Use webpack stats or a bundle analyzer to identify one unexpectedly large dependency and propose a split or replacement.

Catalog research notes

  • Webpack 5 is still the active major line, with ongoing 5.x stability and compatibility updates.
  • Persistent filesystem caching and build performance tuning in 5.x continue improving large-project rebuild speed.
  • Module Federation adoption has grown, with stronger ecosystem patterns for micro-frontend deployments.
  • Asset Modules and improved ESM support have reduced reliance on older file/url/raw loader setups.
