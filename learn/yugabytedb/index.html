YugabyteDB

postgresql-compatible api and distributed storage

Distributed SQL database

Why learn YugabyteDB?

Useful for evaluating resilient relational applications. Compatibility should be tested against actual SQL features, extensions, and client behavior.

Where it came from

YugabyteDB provides distributed database capabilities with a PostgreSQL-compatible SQL interface. Its architecture separates application access from distributed storage responsibilities.

Build your understanding

Work through these exercises in order. Try the task before opening a reference.

  1. Connect with a compatible SQL client.
  2. Create a table and transactional update.
  3. Test the SQL features used by an existing application.
  4. Inspect replication across a test cluster.
  5. Verify application handling of transient node failures.
